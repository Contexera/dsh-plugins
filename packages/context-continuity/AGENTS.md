# Repository Guidelines

## Scope and authority

`dsh-context-continuity` is the extracted context-continuity engine: a subject's
context lived as one continuous timeline across many physical Sessions. It is a
standalone DeepSeek Harness plugin package, consumed by hosts (the Agent Team
today, Loom or a single-subject harness later) as an external dependency.

Authority order:

1. **Current behavior:** `src/` and `tests/`.
2. **Maintained guidance:** this file and `README.md`.
3. **Harness contract:** the applicable `../deepseek-harness/docs/` pages and the
   published `@deepseek-ai/dsh-*` package declarations.

## Architecture guardrails

- **The engine stays host-agnostic.** `src/` may import only its own relative
  modules, `node:` builtins, and the declared `@deepseek-ai/dsh-*` peers;
  `npm run check:boundaries` enforces exactly that list. Never import a host
  package (`@wowyuarm/dsh-agent-team`, Loom) or a sibling Harness source path —
  a host-specific leak defeats the reason this package exists.
- **Section names in `message-codec.ts` are frozen.** They are read back out of
  logs written by earlier generations; changing one silently breaks decoding of
  its own history. The codec is parameterized by `pluginId` and the two
  prose lines, and by nothing else.
- **Naming schemes belong to hosts.** Session ids and rollover request ids come
  from `ContextContinuityHost.rolloverIdentity`; the engine derives no identity
  of its own.
- **Domain anchors arrive as host fold contributions** (`DomainBoundary`), never
  as engine-side domain knowledge.
- Depend on **published** `@deepseek-ai/dsh-*` packages (prebuilt `lib/`). Do not
  add path mappings to a Harness checkout: fast tests are a reason this package
  was extracted.

## Code and documentation conventions

- ESM, strict TypeScript, `.ts` local imports, `exactOptionalPropertyTypes`-clean.
- Keep production code self-explanatory through names, types, and structure;
  comments state non-obvious constraints and reasons, never restate behavior.
- Update `README.md` and the tests when a change alters the public contract
  (`ContextContinuityHost`, the exported codec, or the projection state types).
- `lib/` is generated by `npm run build`; never hand-edit it.
- One commit message: a single Conventional Commits subject line
  (`type: lowercase imperative summary`), no body.

## Checks

Run the narrowest applicable check, then escalate for the changed surface:

```bash
npm run typecheck        # strict types over src + tests
npm test                 # package boundary check + unit tests
npm run build            # confirm the package still emits and imports
```

A change to `coordinator.ts` or `message-codec.ts` is expected to come with
tests that pin its ordering or envelope guarantees.
